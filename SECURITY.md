# Política de seguridad

## Soporte
Se soporta el estado publicado desde main en solucionesgea.com.

## Reporte
No publiques detalles explotables en un issue público. Usa un canal privado del propietario o GitHub Security Advisories cuando esté habilitado.

Incluye componente/ruta, impacto, reproducción y evidencia.

## Prioridad
Critical/Blocker: contención inmediata.  
High: bloquea siguiente release.  
Medium/Low: priorización por riesgo.

Una credencial expuesta se considera comprometida y debe rotarse; borrarla del último commit no basta.

Esta política no autoriza pruebas intrusivas contra proveedores externos.
